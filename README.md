# WechatScreenshot · 微信朋友圈截图生成器

在手机或电脑浏览器中制作微信朋友圈「详情页」样式的图片。填写昵称、上传头像、粘贴公众号文章链接，再设置点赞头像和转发时间，即可预览并保存 PNG 图片。

**[点击这里，直接在线使用 →](https://bruce-lyx.github.io/WechatScreenshot/)**

手机打开网页即可使用，无需下载软件、运行命令或保持电脑开机。也可以通过浏览器菜单「添加到主屏幕」，下次从桌面打开。

> **使用范围：**仅用于个人应付强制转发等情形。请勿批量制作、冒充真实记录、造谣诽谤或用于商业宣传。

## 能做什么

- **制作朋友圈详情图**：支持纯文字、网页 / 公众号分享、单张图片和九宫格图片。
- **自动填写公众号信息**：粘贴文章链接后读取标题、封面和公众号出处，也可手动修改或上传封面。
- **设置点赞效果**：调整点赞数量，随机分配头像，或上传自己的头像库；可将第一个点赞头像设为发布者。
- **编辑内容与时间**：修改昵称、头像、正文、定位、转发出处，以及完整的年月日和时分。
- **切换微信界面样式**：支持浅色 / 深色界面、iOS 通知栏、自定义状态栏和随机信号电量。
- **保存和分享图片**：实时预览，导出 PNG，支持手机系统分享。当前不提供评论回复编辑。

## 怎么使用

1. 打开 **[在线工具](https://bruce-lyx.github.io/WechatScreenshot/)**。
2. 填写昵称、上传头像，选择要制作的内容类型。
3. 分享公众号文章时粘贴文章链接，等待标题、封面和出处自动填入；按需调整正文、时间、点赞和主题。
4. 确认预览后，点击「保存 PNG 图片」或「分享」。

公众号读取和远程头像库需要联网。微信可能限制文章访问；自动读取失败时可重新获取，或手动填写信息并上传封面。

设置和压缩后的图片默认保存在当前浏览器中，下次可以继续编辑。取消「保存设置到本机」可停止保存，点击「清除保存的设置」可删除已有数据。上传的本地图片和生成图片在浏览器中处理；自动读取文章时，文章链接会发送到本项目的读取服务。

## 在自己的电脑上运行

在线使用不需要配置以下内容。需要本地运行时，安装 **Node.js 24.5–24.x**，下载项目后：

- **Windows**：双击 `启动工具.cmd`，自动启动服务并打开浏览器。
- **其他方式**：在项目目录运行 `npm start`，然后访问 `http://localhost:8765`。

本地使用期间保持服务运行。同一 Wi-Fi 下的手机可访问启动窗口显示的局域网地址。直接打开 `index.html` 可以手动编辑和绘图，自动获取公众号信息需要运行服务。

## 自行部署与开发

本项目由单页 HTML 编辑器和 Node.js 文章读取服务组成，无需安装第三方运行依赖。

- [完整网页部署与手机使用说明](DEPLOY.md)
- [GitHub Pages 网页 + 在线读取服务配置](GITHUB-PAGES.md)

GitHub Pages 托管网页，在线读取服务负责获取公众号文章和封面。服务对临时网络错误进行有限次数的自动重试；遇到平台页或验证页会明确报错，避免将其当作文章信息。

运行 `npm test` 可检查文章解析、地址校验、网络重试、服务启动和静态网页构建。
