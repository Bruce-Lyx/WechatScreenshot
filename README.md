# 朋友圈详情图制作

当前发布目标：[`Bruce-Lyx/wechat-tool`](https://github.com/Bruce-Lyx/wechat-tool) → `https://bruce-lyx.github.io/wechat-tool/`。这是独立项目站点，根地址可留给以后的个人主页。源码上传、Pages 启用和在线接口部署分别完成后，才能完整在线使用。

手机优先的单页网页应用，参考上游朋友圈截图工具的功能，并按新的微信深色“详情”界面重做截图样式。

主要在手机上使用时，推荐将完整项目部署为 HTTPS 在线网页，并添加到主屏幕；之后无需在手机上运行命令，也不需要电脑开机。仓库已包含 Render 部署配置、应用图标及 PWA 离线网页支持，完整步骤见 [手机与在线部署](DEPLOY.md)。GitHub Pages 单独托管静态 HTML 不能运行公众号读取接口。

如果要使用 `github.io` 作为入口，项目也已支持 GitHub Pages 网页加 Render 读取接口：[按这份步骤配置](GITHUB-PAGES.md)。发布时通过 GitHub 仓库变量 `ARTICLE_API_URL` 写入接口域名，在 Render 设置 `ALLOWED_ORIGINS` 为自己的 Pages 来源域名即可。

## 使用

Windows 双击 `启动工具.cmd`，会启动服务并自动打开网页，无需手动输入地址。服务已经启动时会直接打开现有网页。电脑需要 Node.js 24.5 或更新版本，启动器也会识别本机 Codex 随附的 Node.js。无需安装第三方依赖，也可运行 `npm start` 后访问 http://localhost:8765 。使用期间保持启动窗口运行。

重复启动会通过不经过代理的本机连接识别现有工具并打开它；如果默认 8765 端口被其他程序占用，会自动尝试 8766 等后续端口，并打开实际使用的地址。

手机与电脑连接同一 Wi-Fi 后，打开启动窗口显示的手机访问地址。若要在外网使用，需要把整个项目部署到可运行 Node.js 的主机；仅上传 `index.html` 的静态托管不提供文章读取接口。直接双击 HTML 仍可手动编辑与绘图，但自动获取文章需要上述服务。

昵称、文字/网页分享/单图/九宫格、封面和图片上传、视频播放标记、位置、分享来源、点赞头像、日期时间、通知栏和浅色样式都可编辑。生成后可保存 PNG 或调用手机系统分享。评论回复编辑暂时关闭，预览中不再添加默认评论。

设置和压缩后的图片默认保存在当前浏览器本机。取消“保存设置到本机”后不会保存；“清除保存的设置”可移除此前保存的数据。文章元数据及远程头像库需要联网，其余绘图和本地图片处理都在浏览器内完成。

首次打开会自动尝试加载上游默认点赞头像库，每次生成时会重新随机分配头像。选择“分享网页/公众号”后粘贴文章链接，浏览器调用本项目的 `/api/article`；服务直接读取微信文章的 `msg_title`、`msg_cdn_url`、`js_name` 或 `nickname = htmlDecode(...)`，不会把个人作者作为公众号名称。平台页和验证页会被拒绝，正文第一张图片不会被当成封面。

封面通过本项目的 `/api/image` 下载，浏览器确认图片可解码后，才同时填写标题、公众号出处和封面，并把封面转为本机图片数据用于预览及 PNG 导出。自动获取不再依赖公共跨域代理；服务端支持系统环境中的 HTTP_PROXY/HTTPS_PROXY/NO_PROXY。微信可能对服务所在网络返回验证页，此时页面明确报错，不填写平台页标题。

转发日期与时间默认取当前设备时间，截图中始终显示完整年月日和时分，日期与时间都可编辑。

生成图以用户提供的 1080 × 2412 深色微信截图为基准。HTML 内嵌从参考图中提取的固定顶部和底栏，不含文章、昵称、头像或评论内容，单独复制 HTML 也能手动编辑及生成；时间依然可设，勾选随机选项后可随机电量、网速和信号强度。默认关闭随机状态以匹配参考图。内容区对齐参考图的头像、卡片、来源、日期、删除/更多按钮和点赞网格；浅色、iOS 与自定义状态栏选项仍可使用。

浅色模式使用用户提供的同尺寸浅色截图顶部与底栏，以及白色背景、浅灰卡片、深色正文、灰色日期和蓝灰昵称。切换主题保留原有内容、几何位置及尺寸，普通正文和链接颜色会随主题调整；评论内容继续关闭。

运行 `npm test` 检查平台页拒绝、微信字段解析、出处优先级及地址校验。已用用户提供的文章链接完成真实接口和 Edge 浏览器端验证：标题“回顾 | 2026.09.26-27黄草梁”、公众号“北大山鹰社MAPKU”，实际封面下载、Canvas 预览与 PNG 导出成功。

## 保留的上游功能

- 纯文字、网页/公众号文章、单张图片、九宫格图片四种动态类型
- 微信表情、话题和网址显示；上传文章封面；公众号标题/封面自动获取
- 点赞数量、自定义远程或本地头像库、首个点赞头像固定为发布者
- 定位、转发来源、发表/截图时间、截图高度与按屏幕比例自动设定
- APP 图标、随机通知栏状态、自定义通知栏图片、iOS 通知栏、浅色界面
- 本机保存设置、下载 PNG 和系统分享
